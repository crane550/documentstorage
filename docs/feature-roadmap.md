# Feature priorities

The user wants all four feature sets below, starting with conversational document questions and folder planning. Prioritize useful feature work; do not substitute a general maintenance/hardening project for these milestones.

- [x] **Ask documents:** persistent scoped conversations, indexed passage retrieval, follow-up questions, evidence quotes, original-document links and cited PDF page previews.
- [x] **AI folder planning:** conversational tree proposals, reuse of existing folders, editable nested names/parents/notes, exact review and creation, canonical filing instructions and resumable progress.
- [ ] **Inbox workbench:** multi-selection and queued reading, filename/destination suggestions in a table, side-by-side preview, direct corrections and approval of selected filings together. Keep the existing single-document workflow available.
- [ ] **PDF tools:** split scans, combine documents, reorder pages and save rotations. Preserve originals until a reviewed new PDF has been created successfully; integrate results with the library/intake index and normal previews.

The first two features are described in [Conversations](conversations.md). Follow-on work should complete the workbench and PDF tools as real usable workflows, not placeholder controls. Real-model results from the server will guide later retrieval and prompt improvements.
